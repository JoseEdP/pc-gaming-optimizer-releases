Install

  1. Download the installer (about 180 MB) and run it.
  2. Open PC Gaming Optimizer. Most changes need administrator rights, and the app offers to restart elevated.
  3. Create a restore point, then try Apply recommended or pick tweaks one by one.

Prefer the command line? Once the package is listed in winget:

winget install CodeNectar.PCGamingOptimizer

All versions and release notes are on GitHub.

Questions

Is it really free?

Yes. There's no paid tier and no trial.

Will it get me banned in online games?

It changes Windows settings and game settings files. It never reads or writes a game's memory or injects anything into it. The overlay uses PresentMon, which reads Windows' own frame timing events.

How do I undo everything?

Each tweak has its own undo, and the Backup page restores Windows restore points you created. Uninstalling the app doesn't change any settings back, so undo first if you want the defaults.

Do I need .NET or anything else?

No. Everything the app needs is included in the installer.

Something went wrong. Where do I get help?

Email support@codenectar.co with your Windows version and what you tried.
